# QuickPay Bank - Frontend

This project is the React frontend for the QuickPay Bank system, connected to a live Render backend.

## Prerequisites
- **Node.js** (v18+)

## Setup Instructions

### 1. Frontend Setup (React)
1. Navigate to the `frontend` folder.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```

## Features
- **Registration**: Full form with validation (Email, Password Match, and Required fields).
- **Professional UI**: Responsive design with a modern fintech aesthetic.
- **Deployed Ready**: Configured for Render deployment.
